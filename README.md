# 25マス文字式計算プリント

中学生向けに、文字式の加法プリントと英語アクティビティプリントを生成するWebアプリです。

## Features

- 縦横にランダムな1次式を表示
- 25マスの足し算プリントを生成
- 正負の数、式の値、比例式、展開、因数分解、平方根、二次方程式の5×5計算練習を生成
- 一次方程式の25マス練習を生成
- 途中式を書ける3×3の連立方程式練習を生成
- 数字だけの操作と文字式を組み合わせる乗除25マスを生成
- 係数・定数の範囲を調整
- 正の数だけ、正負ミックス、負の数多めを選択
- 解答つき印刷のオン/オフ
- 合言葉による同じ問題の再生成
- 中学生英語向けの「25ライト英作文」「書きかえミッション」「単語・熟語ミッション」
- 英語は短い記入欄と語群を使い、時制・助動詞・不定詞・比較・受け身・現在完了などを混ぜて出題
- 英語は学年に加えて、be動詞・一般動詞・疑問文・三単現・進行形・不定詞・受け身・現在完了などの主要文法単元で絞り込み可能
- 中1前半、中1全体、中2（受け身前）、中2（受け身まで）、中3までの範囲切り替え

## Usage

`index.html` をブラウザで開くだけで使えます。
